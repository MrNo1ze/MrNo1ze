# Приватная статистика профиля

`build_private_stats.py` запрашивает GitHub REST API и создаёт карточку
`assets/private-stats.svg` и агрегаты `assets/private-stats.json`. Названия,
адреса репозиториев и токен в файлы и логи не попадают.

## Что считается

- Только приватные репозитории самого владельца профиля, включая архивы и форки.
- Все языки из `/repos/{owner}/{repo}/languages`, без ограничения на первые пять.
  Для каждого: байты, доля общего объёма и число репозиториев с этим языком.
- Размер — байты кода в основных ветках по GitHub Linguist. Это не число строк,
  не размер Git-истории и не объём кода, написанного лично владельцем.
  Linguist исключает распознанные зависимости и сгенерированные файлы;
  языки данных и конфигурации могут не входить в статистику GitHub.
- «Push за 30 дней» — число репозиториев с `pushed_at` за последние 30 суток,
  включая push других участников и ботов. «Вне архива» не означает активность.
- `KiB`, `MiB`, `GiB` — единицы по 1024. JSON хранит точные байты,
  карточка округляет объёмы и доли до двух знаков; очень малые доли — `<0.01%`.
- Время расчёта в JSON — UTC, в карточке — московское. Анализ Linguist после
  push выполняется GitHub в фоне: новый запуск читает готовую статистику API,
  а не заставляет GitHub немедленно заново разобрать исходники.

## Доступ и запуск

В Actions нужен секрет `STATS_TOKEN`: fine-grained PAT владельца с доступом
ко **всем репозиториям** и `Metadata: Read-only`, либо classic PAT со scope `repo`.
Встроенный `GITHUB_TOKEN` Actions остальные приватные репозитории не видит.
Локально PAT передаётся переменной `STATS_TOKEN` (также поддержан `GITHUB_TOKEN`).

```sh
python3 scripts/build_private_stats.py --self-check
python3 scripts/build_private_stats.py
```

Workflow работает ежедневно, вручную и после изменения сборщика в `main`.
Ручной запуск строит карточку из актуальной основной ветки и публикует туда же.
Проверки pull request не получают PAT и ничего не публикуют.

Отсутствие PAT, неверный владелец, пустой ответ, ошибка API или несовпадение
числа репозиториев с `/user.owned_private_repos` останавливают публикацию.
Если API не возвращает этот счётчик, карточка честно указывает, что охват
ограничен доступными токену репозиториями (`coverage_verified: false`).

При каждом расчёте SVG, JSON и ссылка в README записываются одним коммитом.
В URL картинки добавляется хеш SVG: повторный расчёт в тот же день получает
новую версию ссылки и не зависит от кеша прежнего URL. Время и агрегаты видны
в Summary запуска Actions. Перед push используется rebase, чтобы сохранить
параллельные коммиты workflow со змейкой.

Источники: [языки в REST API](https://docs.github.com/en/rest/repos/repos#list-repository-languages),
[работа Linguist](https://github.com/github-linguist/linguist/blob/main/docs/how-linguist-works.md),
[кеш картинок GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/about-anonymized-urls).
